## 코드 분담
- "팀장 작성 → 신입 리뷰·설명" 방식. 코드는 AI가 작성, 나는 PR에서 동작 확인과 설명

## AI가 한 일
- `AXRWeapon`: 엔진 기본 도형(Cube, Cylinder)으로 임시 소총 모양, 원점 = 손잡이를 쥔 손의 중심, `Muzzle` SceneComponent
- `UXRWeaponData`: 양손 파지 기준값(5/7cm, 20~30cm)과 사거리를 담는 데이터 에셋 클래스. 에셋이 없으면 클래스 기본값 사용
- `AXRFPSPawn::EquipWeapon()`: 주 손 Grip에 `SnapToTargetNotIncludingScale`로 장착, 손 컴포넌트가 무기를 기억
- 디버그: 총구 축, 총구 방향 노란 선, 상태줄에 무기 이름
- 데스크톱 양손 파지 프리셋을 실제 총열 높이에 맞춰 조정 (총열 중심선이 손잡이보다 9cm 위)
- 설계 변경: 메시 소켓 대신 SceneComponent로 총구 표시 (기본 도형 조합이라 소켓을 붙일 단일 메시가 없음) → 설계 문서 갱신

## AI가 틀렸거나 고친 부분
- 디버그 컴포넌트에서 `UXRWeaponData` 헤더 include 누락 → 빌드 실패 1회. 연쇄 오류(Printf 형식 검사)도 같은 원인이었음
- 람다에서 static 지역 변수를 캡처하려던 코드를 빌드 전에 발견해 수정 (C++ 규칙상 static 변수는 캡처 대상이 아님)
