# AI 활용 로그

이 폴더는 작업 단위마다 **어떤 AI·모델을, 왜 골랐고, 무엇을 검증하고 고쳤는지** 기록한다.
"AI가 만들었다"가 아니라 "AI를 이렇게 판단하며 썼다"를 보여주는 것이 목적이다.

## 기록 템플릿

파일명: `YYYY-MM-DD-작업이름.md`

```markdown
# 작업 이름

- 날짜 / 마일스톤:
- 소요 시간:

## 사용한 도구와 모델
| 작업 | 도구 | 모델 | 선택 이유 |
|---|---|---|---|

## AI가 한 일 / 내가 한 일
- AI:
- 나:

## AI가 틀렸거나 내가 고친 부분

-
```
