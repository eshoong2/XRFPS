## AI가 한 일
- `UXRHandComponent`(손 하나의 상태), `UXRDebugDrawComponent`(디버그 전담) 추가
- Pawn에 MotionController 4개(LeftGrip/LeftAim/RightGrip/RightAim), 손 컴포넌트 2개, `PrimaryHandSide` 변수 추가
- 입력 소스에 `ShouldApplyFrameToComponents()` 추가: 데스크톱은 프레임 포즈를 컴포넌트에 직접 적용, OpenXR은 엔진이 적용
- 엔진 소스로 확인: `UMotionControllerComponent`는 추적이 안 될 때 위치를 덮어쓰지 않음 → 데스크톱에서 직접 넣은 위치가 유지됨
- `.vsconfig` 추가 (VS 솔루션 생성 시 만들어진, 프로젝트에 필요한 VS 구성요소 목록)

## AI가 틀렸거나 고친 부분
- 이번 단계에서는 빌드 실패 없음
- VS에서 파일이 수정되지 않는다는 문의 → 원인 확인 중 프로젝트에 VS 솔루션(.sln)이 아예 없었음을 발견하고 생성 (지금까지 명령줄로만 빌드해서 생기지 않았음)

- (리뷰어 확인 예정) 에디터 Play에서 손마다 Grip·Aim 축, 상태줄의 주 손 트리거 값
