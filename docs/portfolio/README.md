# 포트폴리오 (노션)

노션 포트폴리오 페이지의 원본을 둔다.

- [notion-page.md](notion-page.md): 노션 페이지 뼈대. 전체를 복사해 노션에 붙여 넣으면 제목·표·인용·구분선이 그대로 변환된다.
- `📌` 표시는 채워야 할 자리다.
- 저장소: https://github.com/eshoong2/XRFPS

## 링크 규칙

| 대상 | 형식 |
|---|---|
| 문서·코드 파일 | `https://github.com/eshoong2/XRFPS/blob/main/경로` |
| 폴더 | `https://github.com/eshoong2/XRFPS/tree/main/경로` |
| 특정 코드 줄 | 커밋 해시 고정 링크 `.../blob/<커밋해시>/경로#L10-L30` |

특정 코드 줄을 가리킬 때는 `main` 대신 **커밋 해시**를 쓴다. 코드가 바뀌어도 링크가 엉뚱한 줄을 가리키지 않는다.
GitHub에서 파일을 열고 `y` 키를 누르면 해시 고정 링크로 바뀐다.
