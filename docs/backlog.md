# 백로그

MVP 범위 밖이지만 버리지 않고 보관하는 아이디어.
새 아이디어는 바로 구현하지 않고 여기 먼저 적는다. 마일스톤을 시작할 때 이 목록에서 고른다.

| 아이디어 | 나온 곳 | 메모 | 확장 여지 |
|---|---|---|---|
| 무기 교체 (죽인 상대의 총 줍기) | M1 설계 회의 (2026-10-18) | 떨어진 총, 줍기, 동시 줍기 서버 중재, 탄약 상태 이전, 스노우볼 밸런스 | `EquipWeapon()` 재사용 |
| 왼손잡이 지원 | VR 템플릿 분석 (2026-10-16) | 설정 메뉴에서 주 손 선택, 라운드 중 고정 | `PrimaryHand` 변수 |
| 탄도 방식 사격 (탄속, 낙차) | M1 설계 회의 | 장거리 무기가 생기면 검토 | `TraceShot()` 내부만 교체 |
| 총 선택 UI | M1 설계 회의 | 라운드 시스템과 함께 (M2 이후) | `EquipWeapon()` |
| 재장전 동작 | M1 설계 회의 | 보조 손 그립 버튼이 비어 있음 (양손 파지는 위치만으로 판정) | — |
| 양손 파지 진입 후 안정화 시간 | M1 설계 회의 | M3 조준 안정도 설계에서 결정 | — |
| 녹화·재생 입력 소스 | ADR-0001 | 서버 검증 테스트, 비정상 데이터 재생 | `UXRInputSource` 파생 |
