# 02. VR 템플릿 분석

- 작성일: 2026-10-16
- 작성자: 박세훈
- 목적: M1 설계 전, UE 5.8 VR 템플릿의 플레이어 구조를 파악하고 우리 게임에 쓸 것을 정한다

## 1. Pawn 구성 요소
| 컴포넌트 | 역할 |
|---|---|
| VROrigin | 플레이 공간 바닥 기준점. 아래 컴포넌트들이 모두 이 기준으로 위치를 가짐 |
| Camera | 머리(HMD) |
| MotionController Left/Right Grip | 손으로 쥔 중심. 물건을 붙이는 기준 |
| MotionController Left/Right Aim | 가리키는 방향. 메뉴, 텔레포트 조준 |
| TeleportTraceNiagaraSystem | 플레이어 이동 경로나 목적지를 표시한다 |
| VRNotifications | 헤드셋 관련 이벤트를 알려준다 |

## 2. 잡기 흐름 (Grab Left Pressed)
입력핀의 출력 노드가 Triggered 상태가 되면 Get Grab Component Near Motion Controller에서 가장 가까운 Grab Component을 출력하게 되고 유효한 값인지를 확인하고 Try Grab을 실행한다 실행 결과가 참이면 왼쪽 손에 Component를 쥔다.

### 3. 핵심 발견
- Grip과 Aim의 차이
컨트롤러의 표준 포즈 Grip과 Aim의 차이는 Grip은 손으로 쥔 중심에 위치하고 손에 든 물건을 붙이는데 사용되고 Aim은 컨트롤러의 앞에 위치해 가리키는 방향을 나타내고 메뉴 선택 같은곳에 사용된다. 우리 게임에서는 총구 방향을 Aim으로 가져오는 것보다 총을 Grip에 붙이고 총을 잡은 위치에서 총구 방향을 정하는 방식이 실제 탄이 나가는 방향이랑 맞을 것 같다. 
- GrabType Snap
GrabType이 Snap방식이면 미리 정해둔 위치와 각도로 손에 맞춰지게 된다. 이 방식이 손과 총 사이 오프셋이 항상 같아서, 서버가 Grip 포즈만 받으면 총구 위치·방향을 다시 계산할 수 있다.
- 햅틱
햅틱은 촉각 피드백이라 불리는 컨트롤러 진동이다. 물건을 잡는 순간에 진동을 줘서 '잡았다'라는 느낌을 전달해 줄 수있다. 
- 햅틱 실행 원칙
잡기·발사 진동처럼 느낌을 위한 연출은 클라이언트에서 즉시, "적을 맞혔다" 같은 결과 확인 진동은 서버 판정을 받은 뒤

- 넘겨잡기
다른 손이 같은 물건을 잡으면 빼앗아 가고(넘겨잡기), 원래 손의 참조를 비워, 양손 파지가 안된다.

## 4. 우리 게임 적용 판단
| 템플릿 기능 | 판단 | 이유 |
|---|---|---|
|VROrigin|필요|상대위치의 기준점으로 사용|
|Camera |필요|머리 위치와 손의 위치값을 비교해서 자세 판정에 사용|
|Grip |필요|총의 위치와 총구 방향 정하는데 사용|
|Aim |필요|UI전용으로 필요|
|텔레포트 이동 |변경 : 스틱 연속 이동으로 교체|  끊기지 않게 자연스러운 이동|
|넘겨잡기 |제외|   주손과 보조손의 역할을 고정|
|스냅 회전 |필요|안정도는 로컬 좌표로 계산|
|GrabType Snap|필요|서버가 Grip 포즈만으로 총구를 계산할 수 있게|
|햅틱 |필요|양손 파지 성공 신호, 반동|
|메뉴 가리키기 |필요|게임 중 UI사용 시|
|VRNotifications|필요|클라이언트의 변화를 감지하고 그 구간을 조준 안정도 계산과 치트 검증에서 제외|



## 5. 양손 파지 판정 기준 (초안)
1. 보조 손이 총열 선 둘레 5cm이내
2. 두 손 사이의 거리 20cm~30cm
3. 총 로컬 좌표에서: 보조손.X > 주손.X

## 6. M1 설계 회의 안건
- 이동 방식: 스틱 연속 이동 + 멀미 완화 옵션
- 조준 안정도 좌표계: VROrigin 로컬
- 주 손 변수(PrimaryHand)와 왼손잡이 지원 시점
- 무기 데이터 분리 (판정 기준값)
- 트래킹 끊김 처리 흐름
- 총열 선 디버그 표시
