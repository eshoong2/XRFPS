# 02. VR 템플릿 분석

- 작성일: 2026-10-16
- 작성자: (박세훈)
- 목적: M1 설계 전, UE 5.8 VR 템플릿의 플레이어 구조를 파악하고 우리 게임에 쓸 것을 정한다

## 1. Pawn 구성 요소
(Componets 목록에는 바닥 기준점인 VROrigin안에 Camera, MotionControllerLeftAim, Grip, MotionControllerRightAim, Grip,(모션 컨트롤러 컴포넌트 4개), TeleportTraceNiagaraSystem 그리고 VRNotifications가 있다 OpenXR은 컨트롤러마다 표준 포즈가 두 개 존재하여 양손으로 총 4개의 모션 컴포넌트가 존재한다.)

## 2. 잡기 흐름 (Grab Left Pressed)
(트리거가 완료 상태가 되면 Get Grap Component Near Motion Controller에서 가장 가까운 Grap Component을 출력하게 되고 유효한 값인지를 확인하고 Try Grab을 실행한다 실행 결과가 참이면 왼쪽 손에 Component를 쥔다. 양 손의 흐름은 예외 상황을 줄이기 위해 주손과 보조손으로 나누어 역할을 부여한다.)

## 3. 핵심 발견
- Grip과 Aim의 차이
컨트롤러의 표준 포즈 Grip과 Aim의 차이는 Grip은 손으로 쥔 중심에 위치하고 손에 든 물건을 붙이는데 사용되고 Aim은 컨트롤러의 앞에 위치해 가리키는 방향을 나타내고 메뉴 선택 같은곳에 사용된다. 우리 게임에서는 총구 방향을 Aim으로 가져오는 것보다 총을 Grip에 붙이고 총을 잡은 위치에서 총구 방향을 정하는 방식이 실제 탄이 나가는 방향이랑 맞을 것 같다. 
- GrabType Snap
GrapType이 Snap방식이면 미리 정해둔 위치와 각도로 손에 맞춰지게 된다. 이 방식이 Free나 Custom방식으로 하는것보다 계산과 검증이 단순해진다.
- 햅틱
햅틱은 촉각 피드백이라 불리는 컨트롤러 진동이다. 물건을 잡는 순간에 진동을 줘서 '잡았다'라는 느낌을 전달해 줄 수있다.

## 4. 우리 게임 적용 판단
| 템플릿 기능 | 판단 | 이유 |
|VROrigin    |필요|  상대위치의 기준점으로 사용|
|Camera      |필요|  머리 위치와 손의 위치값을 비교해서 자세 판정에 사용|
|Grip        |필요|  총의 위치와 총구 방향 정하는데 사용|
|Aim         |필요|  UI전용으로 필요|
|텔레포트 이동 |변경 : 스틱 연속 이동으로 교체|  끊기지 않게 자연스러운 이동|
|넘겨잡기     |제외|   주손과 보조선의 역할을 고정|
|스냅 회전    |필요|안정도는 로컬 좌표로 계싼|
|GripType Snap|필요|서버가 Grip 포즈만으로 총구를 계산할 수 있게|
|햅틱         |필요|양손 파지 성공 신호, 반동|
|메뉴 가리키기 |필요|게임 중 UI사용 시|
|VRNotifications|필요|헤드셋을 벗거나 끊길때 서버에서 처리|



## 5. 양손 파지 판정 기준 (초안)
기준 1. 보조 손이 총열 선 둘레 5cm이내 -> 총열 아래쪽 판정
기준 2. 두 손 사이의 거리 20cm~30cm -> 총열에 따라 얼마나 앞에 있나
기준 3. 보조손과 주손의 총 기준 로컬좌표 Y축 비교
