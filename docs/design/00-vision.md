# 00. 프로젝트 비전 및 목표 정의

- 작성일: 2026-10-02
- 상태: 확정 (MVP 범위)

## 1. 한 줄 정의

XR 기기의 HMD + 손/컨트롤러 트래킹을 활용해, **플레이어의 실제 자세와 조준 상태가 전투 성능에 영향을 주는** 서버 권위형 멀티플레이 FPS.

## 2. 프로젝트의 두 가지 산출물

| 산출물 | 설명 |
|---|---|
| 게임 | UE5(C++ 중심)로 만든 Quest 3S용 XR 멀티플레이 FPS |
| 과정 | 기초 지식을 가진 개발자가 작업마다 AI와 모델을 **선택**하고, 결과를 **검증**하고, 판단을 **기록**한 과정 (`docs/ai-log/`) |

## 3. 핵심 설계 원칙: 트래킹 데이터와 서버 권위

트래킹(HMD, 손 위치·회전)은 클라이언트 기기에서만 측정된다. 서버는 플레이어의 몸을 볼 수 없으므로 서버 권위를 다음과 같이 정의한다.

| 구분 | 클라이언트 | 서버 |
|---|---|---|
| 역할 | 원본 트래킹 데이터를 **입력**으로 전송 | 데이터가 물리적으로 가능한지 **검증** |
| 금지 | 판정 결과 전송 (예: "내 흔들림은 0") | — |
| 계산 | — | 조준 안정도, 양손 파지 여부, 탄 퍼짐, 명중, HP |

서버 검증 예시:
- 손과 HMD 사이 거리가 팔 길이 한계를 넘지 않는가
- 프레임 간 손 이동 속도가 비정상적이지 않은가
- 전송 빈도와 데이터 패턴이 정상 범위인가

> 완벽한 치트 방지는 목표가 아니다. "클라이언트를 신뢰하지 않고 검증하는 구조"를 설계하고 문서로 보여주는 것이 목표다.

## 4. 전투 메커니즘 후보

| ID | 메커니즘 | 측정 | 영향 | 일정 |
|---|---|---|---|---|
| A | 조준 안정도 | 최근 N프레임의 총구 흔들림 | 탄 퍼짐 | **MVP** |
| C | 양손 파지 | 보조 손이 총열을 잡았는가 | 흔들림 보정, 반동 감소 | **MVP** |
| B | 실제 자세 | HMD 높이 (서기/앉기/엎드리기) | 히트박스, 정확도 | M4 이후 |
| D | 정조준 | 가늠쇠-눈 거리 | 정확도↑, 이동속도↓ | 미정 |
| E | 기울이기 | 머리-몸통 수평 오프셋 | 엄폐 노출 범위 | 미정 |

MVP는 A + C를 **"무기 핸들링"** 이라는 하나의 시스템으로 묶는다. C(양손 파지)의 결과가 A(안정도)의 입력이 되는 구조다. → [ADR-0002](../decisions/ADR-0002-mvp-mechanics.md)

## 5. MVP 완료 기준

- [ ] 2명이 Listen Server로 접속하고, 서로의 머리·양손·총이 보인다
- [ ] 클라이언트는 트래킹 원본만 보내고, 서버는 범위·속도를 검증한다
- [ ] 서버가 양손 파지 여부를 판정한다
- [ ] 서버가 조준 안정도를 계산하고(양손 파지 보정 포함), 탄 퍼짐에 반영한다
- [ ] 명중 판정과 HP 감소는 서버가 하며, 사망 후 리스폰된다
- [ ] 디버그 HUD로 안정도·파지 상태·퍼짐 수치를 확인할 수 있다

## 6. 개발 환경과 제약

| 항목 | 내용 |
|---|---|
| XR 기기 | Meta Quest 3S **1대** |
| PC | Ryzen 7 7735HS, **내장 GPU Radeon 680M**, RAM 약 13GB |
| 제약 | 외장 GPU가 없어 PCVR(Quest Link) 개발이 사실상 불가 |
| 방식 | **데스크톱 시뮬레이션 + 주기적 Quest 단독 빌드** → [ADR-0001](../decisions/ADR-0001-dev-workflow.md) |
| 2인 테스트 | Quest(단독 앱, 클라이언트) ↔ PC(데스크톱, 서버 겸 플레이어), 같은 Wi-Fi |

## 7. 마일스톤

날짜는 정하지 않는다. 각 마일스톤의 **소요 시간과 막힌 지점**을 기록한다.

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| M0 | 환경 구축 | UE5·VS·Android 빌드 환경, Git, Quest에 빈 앱 실행 |
| M1 | 싱글 플레이 | VR 손, 총 잡기, 사격, 양손 파지 (로컬) |
| M2 | 네트워크 | 트래킹 동기화, 서버 검증, 서버 판정 사격 |
| M3 | 무기 핸들링 | 서버 계산 조준 안정도 + 탄 퍼짐 → **MVP 완료** |
| M4~ | 확장 | 실제 자세(B), 지연 보정 등 |
