# ADR-0002: MVP 전투 메커니즘 — 조준 안정도(A) + 양손 파지(C)

- 날짜: 2026-10-02
- 상태: 채택

## 배경

"실제 자세와 조준 상태가 전투 성능에 영향을 준다"는 컨셉을 구현할 메커니즘 후보는 다섯 가지다. ([00-vision.md](../design/00-vision.md) 4절 참고)
MVP에 모두 넣으면 범위가 커져 완성 가능성이 떨어진다.

## 검토한 대안

| 조합 | 장점 | 단점 |
|---|---|---|
| A + B (안정도 + 자세) | 서버 계산 구조를 잘 보여줌 | 자세(B)는 히트박스 변경·지연 보정과 엮여 MVP로는 무거움 |
| A + B + C | 컨셉을 가장 풍부하게 표현 | 범위 과다, MVP 완성이 늦어짐 |
| **A + C (안정도 + 양손 파지)** | C가 A의 입력이 되어 "무기 핸들링" 하나의 시스템으로 묶임 | 히트박스 쪽 기능은 MVP에서 빠짐 |

## 결정

**A + C를 MVP로, B(실제 자세)는 M4 이후로 미룬다.**

## 이유

- 사용자가 양손 파지(C)를 원했고, C는 A와 데이터 흐름이 자연스럽게 이어진다.
  - 양손 파지 판정 → 흔들림 보정 계수 → 조준 안정도 → 탄 퍼짐
- 두 메커니즘 모두 "서버가 원본 트래킹으로 직접 계산한다"는 핵심 원칙을 보여주기에 충분하다.
- B는 지연 보정(Lag Compensation)과 함께 설계하는 것이 맞아 별도 마일스톤으로 분리한다.
